📋Sistema:
utilizando array de objetos representando os vinhos da vinícola. Cada vinho contem:
    -Nome
    -Tipo (tinto, branco, rosé)
    -Safra
    -Estoque

📋Funções para: 
    -Adicionar novos vinhos ao array
    -Listar todos os vinhos com forEach
    -Mostrar vinhos com estoque baixo usando filter
    -Calcular estoque total com reduce
    -Exibir nomes dos vinhos em caixa alta com map


Todas as interações acontecem via console.log ou alert()
